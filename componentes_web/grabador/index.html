Grabando

Ubíquese como indica la guía amarilla: la cabeza dentro de las esquinas y los hombros entre las dos líneas. Es el mismo encuadre con el que se grabaron las muestras de entrenamiento. De frente y con buena luz. Empiece y termine con las manos abajo.
